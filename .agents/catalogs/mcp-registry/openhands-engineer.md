## 🎯 Visión Arquitectónica

OpenHands es una plataforma agéntica autónoma diseñada para actuar como un ingeniero de software de ciclo completo. Opera dentro de un entorno seguro y aislado (Docker container o microVM), ejecutando herramientas de shell, navegación web, edición sintáctica de archivos y loops de prueba y corrección autónoma:


## 🛠️ Especificación de Herramientas MCP

### 1. `openhands_spawn_task`
Inicia una tarea de ingeniería autónoma en un contenedor aislado con un repositorio o workspace objetivo:

```json
{
  "name": "openhands_spawn_task",
  "description": "Initializes an autonomous software engineering session inside a secure isolated sandbox container to solve an issue, implement a feature, or refactor code.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "task_description": { "type": "string", "description": "High-level goal or GitHub issue description." },
      "repo_path": { "type": "string", "description": "Target workspace or repository path." },
      "base_commit": { "type": "string", "description": "Optional starting commit or branch." },
      "test_command": { "type": "string", "description": "Command used by the agent to verify success (e.g. pytest, npm test)." },
      "max_iterations": { "type": "integer", "default": 25 }
    },
    "required": ["task_description", "repo_path"]
  }
}
```

### 2. `openhands_sandbox_exec`
Ejecuta comandos de terminal en el sandbox con límite estricto de timeout y monitoreo de procesos colgados:

```json
{
  "name": "openhands_sandbox_exec",
  "description": "Executes shell commands inside the OpenHands Docker sandbox with live output streaming and timeout enforcement.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "command": { "type": "string", "description": "Shell command to execute." },
      "cwd": { "type": "string", "default": "/workspace" },
      "timeout_seconds": { "type": "integer", "default": 120 }
    },
    "required": ["command"]
  }
}
```

### 3. `openhands_collect_diff`
Extrae el diff resultante de los cambios aplicados por el agente autónomo para auditoría humana antes de fusionar:

```json
{
  "name": "openhands_collect_diff",
  "description": "Returns the git diff generated by the agentic session, including files changed, unit tests added, and status summary.",
  "inputSchema": {
    "type": "object",
    "properties": {
      "session_id": { "type": "string" },
      "format": { "type": "string", "enum": ["patch", "summary", "sarif"], "default": "patch" }
    },
    "required": ["session_id"]
  }
}
```

## 🏛️ Gobernanza y Directivas de Seguridad

1. **Aislamiento Estricto (Ken Xie / George Kurtz):** Ninguna sesión de OpenHands puede ejecutarse directamente en el sistema host sin contenedor Docker o microVM con privilegios no-root.
2. **Revisión Humana Obligatoria (Jeff Dean / Antigravity):** Ningún pull request o commit generado automáticamente se publicará a ramas protegidas sin validación de pruebas unitarias y revisión de diff.
3. **Control de Presupuesto de Tokens (Andy Jassy):** Cada sesión autónoma debe contar con un límite máximo de iteraciones (`max_iterations <= 30`) y corte automático ante bucles repetitivos de error.
