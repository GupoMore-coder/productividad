# 🐝 Ruflo Multi-Agent Swarm Orchestrator

This skill formalizes the **hive-mind multi-agent swarm orchestration protocol** (Jeff Bezos Day 1 execution speed / Andy Jassy parallel delegation efficiency) using Ruflo.

---

## 🎯 When to Use

* **Large-Scale Parallel Refactoring:** Splitting repository migrations across multiple worker agents simultaneously.
* **Collaborative Multi-Role Problem Solving:** Coordinating architect, implementer, tester, and security reviewer agents in lockstep.
* **Knowledge Graph Ingestion:** Building persistent conceptual relationship maps across complex domains.
* **Decentralized Agent Swarms:** Coordinating independent tasks without single-thread bottlenecking.

---

## 🧭 The 4-Step Swarm Orchestration Loop

```
1. Swarm Topology Definition ──► 2. Parallel Task Dispatch ──► 3. RuVector Graph Synchronization ──► 4. Consensus & Merging
```

### Step 1: Swarm Topology Definition
- Appoint the lead coordinator agent.
- Instantiate specialized sub-agents with strict role boundaries (frontend, backend, QA, security).

### Step 2: Parallel Task Dispatch
- Decompose epic tasks into independent sub-jobs with defined input/output contracts.
- Enforce file resource locking to avoid concurrent write collisions.

### Step 3: RuVector Graph Synchronization
- Workers publish discovered patterns and architectural facts to the shared knowledge graph.
- Other agents query the graph to avoid duplicating research.

### Step 4: Consensus & Merging
- Lead agent synthesizes worker outputs against the acceptance criteria.
- Run unified verification suites before committing the combined solution.

---

## 🛡️ Swarm Safety Guardrails

- [ ] **No Uncontrolled Agent Recursion:** Cap maximum swarm depth to 2 tiers to prevent runaway process loops.
- [ ] **Resource Locking:** Never allow two sub-agents to edit the same file simultaneously.
- [ ] **Budget Awareness:** Monitor aggregate token consumption across all spawned sub-agents.
