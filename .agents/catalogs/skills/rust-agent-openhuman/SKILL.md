# 🧠 Rust Agent OpenHuman

This skill defines the **high-performance local memory and algorithmic context compression standard** (Andy Jassy frugal token economics / Jeff Dean systems efficiency / Larry Fink open-standard storage) for maximizing reasoning quality while minimizing token expenditure.

---

## 🎯 When to Use

* **Context Window Budgeting:** Compressing lengthy multi-file diffs, API schemas, or conversation threads before sending to frontier LLMs.
* **Obsidian-Compatible Knowledge Vaults:** Maintaining a bi-directionally linked Markdown and SQLite memory store on local disk.
* **Low-Latency Rust Agent Harnesses:** Orchestrating personal agent assistants with local speech and desktop mascot features.
* **Air-Gapped Sovereign Notes:** Organizing confidential medical or corporate insights in a private, encrypted vault.

---

## 🧭 The 4-Step TokenJuice & Memory Loop

```
1. Ingestion & AST Tagging ──► 2. Semantic Pruning ──► 3. Fact Vault Sync ──► 4. Lean Prompt Dispatch
```

### Step 1: Ingestion & AST Tagging
- Ingest raw user prompt, system instructions, and historical context.
- Identify core entities, numeric constraints, code signatures, and explicit directives.

### Step 2: Semantic Pruning (TokenJuice)
- Strip decorative adjectives, polite conversational filler, and redundant repeated instructions.
- Compress repetitive log traces into summary counters (e.g. `[12 consecutive successful pings omitted]`).
- Verify that reduction ratio reaches 40-70% without changing semantic intent.

### Step 3: Local Vault Synchronization
- Commit atomic facts and decision records to the local SQLite database.
- Mirror structural changes to Obsidian `.md` files in the workspace knowledge directory.

### Step 4: Lean Prompt Dispatch
- Send the compressed, fact-dense payload to the target reasoning model.
- Verify that response quality equals or exceeds uncompressed baseline.
