# 🎨 Anti-Slop Design & Craftsmanship Guard

This skill enforces the **anti-slop quality standard** (Bernard Arnault luxury differentiation / Steve Jobs uncompromising taste / Andy Jassy zero-waste substance) to ensure interfaces, prose, and code feel human, intentional, and premium.

---

## 🎯 When to Use

* **Frontend Design Audits:** Eliminating repetitive AI design tropes (generic purple-to-blue gradients, floating glassmorphism blobs, arbitrary rounded bento cards).
* **Brand Copywriting Review:** Scrubbing robotic adjectives ("game-changing", "seamless", "delve into", "tapestry") from marketing pages and documentation.
* **Component Refinement:** Ensuring strong typographic hierarchy, intentional white space, and proper accessibility contrast ratios ($4.5:1$ minimum).
* **Code Craftsmanship:** Removing robotic AI comment spam (e.g., `// This function returns the sum of a and b`) in favor of expressive, self-documenting code.

---

## 🧭 The 3 Pillars of Anti-Slop Quality

### Pillar 1: Visual Design & Color Palettes
- **Banned:** Generic AI neon-purple on dark slate (`#7c3aed` gradient to `#3b82f6` on `#0f172a`).
- **Adopted:** Cohesive, intentional brand palettes (e.g. More Paper deep navy, warm alabaster, burnished bronze, surgical teal).
- **Structure:** Replace arbitrary bento-grid layouts with content-informed editorial grids and clear visual hierarchy.

### Pillar 2: Copywriting & Editorial Voice
- **Banned Words:** *Delve, testament, beacon, tapestry, revolutionize, seamless, unleash, game-changing, paramount*.
- **Adopted:** Crisp, active verbs, concrete metrics, straightforward sentences, and authentic technical precision.

### Pillar 3: Code Authenticity
- Write code that looks like it was written by an experienced principal engineer, not a generic auto-complete model.
- Keep comments focused on *why* (business rationale, non-obvious trade-offs), not restating *what* the syntax obviously does.

---

## 🛡️ Anti-Slop Quality Gate

- [ ] **No Generic AI Color Clichés:** Color tokens derived from brand identity, not default prompt templates.
- [ ] **High Text Contrast:** All body text meets WCAG AA standards.
- [ ] **Purged Prose:** Text scanned and cleared of AI buzzword clichés.
